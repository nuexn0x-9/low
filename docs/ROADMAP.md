# LOW Product Roadmap

This roadmap outlines upcoming milestones and planned features for **LOW (Lowcode Oriented Wireframe)**.

---

## Current Status: v1.0.0 (MVP) :white_check_mark:
- [x] Monochrome minimalist mobile wireframe canvas
- [x] Open `.low.json` document lifecycle with revision tracking
- [x] Optimistic concurrency control & snapshot backups
- [x] Built-in component and screen template library
- [x] AI Import Engine (Mock + OpenAI GPT JSON Mode)
- [x] Universal Agent Connect (12 scopes, 18 actions, dry-run, atomic batch, undo)
- [x] Self-hosted Docker Compose deployment & SQLite persistence

---

## Near-Term: v1.1.0 (Q4 2026)
- [ ] **Official MCP Server**: Standalone Model Context Protocol binary (`low-mcp`) for 1-click install in Claude Desktop and Cursor.
- [ ] **Local AI Providers**: Native Ollama and LocalAI integration for 100% private, offline LLM generations.
- [ ] **SVG & PDF Screen Export**: Direct vector export of individual screens or interactive clickable PDF flows.
- [ ] **Custom Color Themes**: Light and dark monochrome variants (OLED pure black, classic zinc, slate).

---

## Mid-Term: v1.2.0 (Q1 2027)
- [ ] **Component Variants & States**: Hover, pressed, active, and disabled component property toggles.
- [ ] **Multi-User Collaboration**: Lightweight presence indicators (who is currently viewing which screen).
- [ ] **Design Token Export**: Generate Tailwind CSS, React Native StyleSheet, or Flutter code snippets directly from `.low.json`.

---

## Long-Term Vision
- [ ] **Agent Pair-Designer**: Agents actively suggest UX layout improvements, accessibility contrast fixes, and touch target size warnings in real time.
- [ ] **Community Template Hub**: Peer-to-peer sharing of open `.low.json` component packs.
